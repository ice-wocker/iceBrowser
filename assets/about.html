ice 浏览器

v5.0.0

极简、便携、零第三方依赖的 Android 浏览器。
纯 Java 编写，单 dex 构建。

核心能力
真正的多标签
每个标签独立 WebView，切换不重载，进程被杀后可恢复
自研 ice 搜索引擎
异步线程池 + HTML 解析，多数据源合并去重，本地 LRU 缓存
广告与追踪器拦截
基于 assets/adblock.txt 规则，支持域名、路径与正则匹配
隐私优先
无痕模式不落盘、不写历史、不保存表单
阅读模式 · 页内查找 · 桌面版
正文抽取可调字号并跟随主题，原生查找替代 JS hack
4 套主题
浅色 / 深色 / 纯黑 / 护眼，可跟随系统，运行时即时切换
技术规格
语言纯 Java（无 Kotlin）
最低系统Android 5.0（API 21）
第三方依赖0
构建方式Termux · aapt + dx 单 dex
数据存储SQLite + SharedPreferences
渲染内核系统 WebView
