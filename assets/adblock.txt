# iceBrowser built-in ad / tracker blocklist
# ============================================================
# FILE FORMAT
#   * Encoding: UTF-8, LF line endings. Rule lines are ASCII-only;
#     comment lines (section titles) may contain non-ASCII text.
#   * Parsed line by line. Blank lines are ignored.
#   * Lines starting with '#' or '!' are comments and are ignored.
#   * '@@<host>'        exception / whitelist: forces the request to be
#                       ALLOWED even if another rule matches. <host> is a
#                       case-insensitive host/URL substring.
#   * '@@re:<regex>'    exception matched against the FULL URL.
#   * 're:<regex>'      Java regular expression matched against the FULL
#                       URL, case-insensitive (Pattern.CASE_INSENSITIVE).
#                       Must be a valid Java regex.
#   * 'path:<text>'     case-insensitive substring rule matched against the
#                       FULL URL; used for path-based blocking,
#                       e.g. 'path:/ads/' or 'path:/pagead/'.
#   * '<text>'          host/domain substring rule. A request is blocked
#                       when the URL host OR the full URL contains <text>.
#                       Always write bare domain stems such as
#                       'doubleclick.net' -- never full schemed URLs.
#   * Precedence: an '@@' exception always wins and allows the request.
# ============================================================
